# 🎯 ماسح عقود بايننس الآجلة — Sniper v4.1

<p dir="rtl">
<strong>نظام آلي كامل</strong> لمسح عقود بايننس الآجلة واكتشاف صفقات اصطياد الذيل الآسيوي (Catch the Dip) والعملات القابلة للانفجار — يعمل على GitHub Actions بلا أي خادم، ويعرض تقريراً تفاعلياً يعمل كتطبيق موبايل.
</p>

## ✨ المزايا

| الميزة | الوصف |
|---|---|
| 🔄 مسح آلي مجدول | يعمل تلقائياً كل 15 دقيقة (أو حسب جدولك) عبر GitHub Actions |
| 🎯 مناطق دخول محسوبة | نقطة الدخول / الوقف / 3 أهداف + مسافات ATR + تصنيف A/B/C |
| 💣 مصائد الانفجار | كشف العملات القابلة للانفجار (Fire Mode) مع بيانات الانفجار السابق |
| 💎 نمط استثماري | متابعة العملات القريبة من الدخول لمتابعة أسبوعية + Smart Money (BOS/CHoCH/Order Blocks) |
| 🔄 تتبع الصفقات | تحديث الصفقات المفتوحة آلياً حتى الهدف أو الوقف (سقف 72 ساعة) |
| 🗑️ زر ريست | مسح كل الصفقات والبدء من الصفر بضغطة واحدة |
| 📊 تقرير HTML تفاعلي | يعمل كتطبيق PWA على الجوال (تثبيت من المتصفح) |
| 📱 إشعارات تيليجرام | ملخص فوري بعد كل مسح + تنبيهات |
| 📦 أرشيف | آخر 10 مسوحات في `history/` |

## 🚀 البدء السريع

1. ارفع هذا المستودع على GitHub (عام) — اتبع **[دليل التثبيت والنشر](guide.html)**
2. فعّل GitHub Pages (Settings ← Pages ← Branch: main)
3. أضف أسرار تيليجرام في (Settings ← Secrets ← Actions)
4. افتح الرابط على جوالك وثبّت التطبيق من المتصفح

## ⚙️ الأوامر

```bash
python3 binance_scanner_standalone.py --run-scan      # مسح جديد + تحديث المفتوح
python3 binance_scanner_standalone.py --confirm-0245  # فحص تأكيد 02:45
python3 binance_scanner_standalone.py --reset         # ريست شامل (مسح كل الصفقات)
python3 binance_scanner_standalone.py --test-all      # 32 اختبار قبول
```

## 🔐 أسرار GitHub (اختيارية — للإشعارات فقط)

> **النظام والتطبيق يعملان بالكامل بدون أي أسرار.** تيليجرام اختياري — إن أردت الإشعارات الفورية أضف:

| السر | المثال | الوصف |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | `7012345678:AAF...` | توكن البوت من @BotFather |
| `TELEGRAM_CHAT_ID` | `5581234567` | معرف دردشتك |

> **الجدولة:** تُعدَّل مباشرة في ملف `.github/workflows/scanner.yml` (سطور `cron`) — انظر الدليل.
> **أزرار التقرير:** تحتاج رمز وصول شخصي (PAT) يُدخل مرة واحدة داخل التقرير من زر ⚙️ — انظر الدليل.
