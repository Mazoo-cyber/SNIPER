🧭 أولاً: ماذا سننجز؟ (الصورة الكبيرة)

سنحوّل المشروع الموجود في ملفاتك إلى نظام يعمل على الإنترنت تلقائياً، وتطبيق على جوالك. هذا ما سيحدث:

GitHub (مجاني) — الملفات تعيش هنا + محرك المسح يعمل تلقائياً كل يوم ⬇ GitHub Pages (مجاني) — تقريرك على الإنترنت: https://اسمك.github.io/sniper/ ⬇ تطبيق الموبايل — أيقونة على شاشة جوالك تفتح التقرير مباشرة ⬇ تيليجرام (اختياري) — إشعار فوري بعد كل مسح — يمكنك تفعيله لاحقاً إن أردت
💡 مبدأ العمل: أنت لا تشغّل شيئاً بنفسك كل يوم. الخادم المجاني (GitHub Actions) يشغّل المسح تلقائياً حسب الجدول الذي تحدده، وينشر التقرير، ويرسل لك الإشعارات. دورك: مراقبة التقرير من جوالك والضغط على الأزرار عند الحاجة.

🧰 ثانياً: ماذا تحتاج قبل البدء؟

1️⃣ حساب GitHub قلتَ إنه جاهز ✅ — سجّل الدخول به على github.com
2️⃣ حساب تيليجرام على نفس الجوال (للإشعارات) — مجاني
3️⃣ الملفات ملف مضغوط جاهز ستنزّله من هذه الصفحة — ابحث عن Sniper_v4.1_جاهز_للرفع.zip

1 إنشاء المستودع (Repository) على GitHub

المستودع = مجلدك الخاص على الإنترنت.

  1. افتح https://github.com وسجّل الدخول.
  2. اضغط زر ＋ في أعلى يمين الصفحة ← اختر New repository.
  3. في صفحة الإنشاء املأ الحقول كالتالي:
    الحقلماذا تكتب
    Repository namesniper (أو أي اسم بالإنجليزي بدون مسافات)
    Descriptionاختياري — مثلاً: ماسح عقود بايننس الآجلة
    Public / Private✅ Public (كما اخترت — مجاني ويعمل التقرير)
    Add a README✅ ضع علامة ✓ (مهم)
  4. اضغط الزر الأخضر Create repository.
💡 ستظهر لك صفحة المستودع الجديدة فارغة تقريباً وفيها ملف README. هذا طبيعي — سنملؤها في الخطوة التالية.

2 رفع ملفات المشروع

  1. من مساحة العمل: نزّل الملف المضغوط Sniper_v4.1_جاهز_للرفع.zip وفك ضغطه على جهازك (زر سحب الملفات للتنزيل يظهر عند فتح الملف).
  2. عد إلى صفحة المستودع على GitHub ← اضغط Add file (زر بجانب زر القوس الأخضر) ← Upload files.
  3. اسحب محتوى المجلد المفكوك (كل الملفات والمجلدات) وأفلتها في صفحة الرفع.
  4. انتظر حتى يرتفع كل شيء (قد يستغرق دقيقة تقريباً — حوالي 20 ملف).
  5. قبل الضغط على الحفظ، تحقق من القائمة أنك ترى:
    .github/ ← scanner.yml داخله ✓
    binance_scanner_standalone.py ✓
    cloud_entry.py ✓   index.html ✓   history/ ✓
    manifest.json ✓   sw.js ✓   icon-512.png ✓ ...
  6. اضغط Commit changes ← اختر Commit directly to the main branch ← اضغط الزر الأخضر.
⚠️ إن لم تظهر مجلدات تبدأ بنقطة مثل .github: بعض المتصفحات لا تسحبها تلقائياً. الحل: أنشئ الملف يدوياً كما في قسم «الرفع من الجوال» بالأسفل (اكتب المسار كاملاً .github/workflows/scanner.yml عند إنشاء ملف جديد وسيُنشئ GitHub المجلدات).

📱 الرفع من الجوال (إن لم يكن لديك كمبيوتر)

الرفع يكون من الموقع (github.com في متصفح الجوال) — تطبيق أندرويد الرسمي ليس أداة رفع. الخطوات:

  1. نزّل الحزمة Sniper_v4.1_جاهز_للرفع.zip وفك ضغطها بتطبيق الملفات (أي مدير ملفات يدعم ZIP).
  2. في متصفح الجوال: أنشئ المستودع (الخطوة 1) ← Add file ← Upload files.
  3. اضغط «اختيار ملفات» ← حدّد كل ملفات الجذر دفعة واحدة (الضغط المطوّل للاختيار المتعدد — حوالي 28 ملفاً مثل index.html وbinance_scanner_standalone.py وicon-512.png وملفات .json...) ← ارفعها واحفظ.
  4. ملف التشغيل التلقائي يُنشأ يدوياً: Add file ← Create new file ← في خانة الاسم اكتب المسار كاملاً: .github/workflows/scanner.yml ← الصق المحتوى من الإطار بالأسفل ← Commit changes.
  5. مجلد history/ لا داعي لرفعه — يُنشأ تلقائياً من أول مسح.
  6. تابع بقية الخطوات (Pages...إلخ) من نفس المتصفح.
💡 محتوى ملف .github/workflows/scanner.yml — انسخه كما هو:
name: Binance Futures Scanner (Riyadh Schedule) on: schedule: - cron: '45 23 * * *' - cron: '5 0 * * *' - cron: '5 8 * * *' - cron: '5 12 * * *' - cron: '5 16 * * *' - cron: '5 20 * * *' workflow_dispatch: inputs: mode: description: 'نوع التشغيل اليدوي' required: true default: 'scan' type: choice options: - scan - confirm - reset permissions: contents: write concurrency: group: binance-scanner cancel-in-progress: false jobs: run-scanner: runs-on: ubuntu-latest timeout-minutes: 25 steps: - name: Checkout repository uses: actions/checkout@v4 - name: Set up Python uses: actions/setup-python@v5 with: python-version: '3.11' - name: Run Binance Futures Engine env: TZ: Asia/Riyadh SCAN_MODE: ${{ github.event.inputs.mode || 'auto' }} SCHEDULE_CRON: ${{ github.event.schedule || '' }} TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }} TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }} run: python3 cloud_entry.py - name: Save updated report & state run: | git config user.name "Binance-Scanner-Bot" git config user.email "bot@users.noreply.github.com" git add index.html *.json 2>/dev/null || true git add -A -- history/ 2>/dev/null || true if ! git diff --cached --quiet; then git commit -m "تحديث التقرير الآلي $(TZ=Asia/Riyadh date '+%Y-%m-%d %H:%M')" git pull --rebase -X theirs origin main || true git push origin HEAD:main fi

3 تفعيل موقع التقرير (GitHub Pages)

بهذه الخطوة يصبح تقريرك موقعاً على الإنترنت يفتحه أي جوال.

  1. في المستودع ← Settings (تبويب أعلى).
  2. في القائمة الجانبية اليسرى ← Pages.
  3. تحت Build and deployment ← المصدر (Source): Deploy from a branch.
  4. تحت Branch ← اختر main ← المجلد: /(root) ← اضغط Save.
  5. انتظر 1–3 دقائق ثم افتح الرابط الذي يظهر أعلى الصفحة (أو مباشرة):
    https://اسم-المستخدم.github.io/sniper/
    استبدل اسم-المستخدم باسم حسابك على GitHub (تراه أعلى يمين موقع GitHub).
✅ إن فتح التقرير على جوالك — تهانئ! النصف الأكبر اكتمل. باقي: الإشعارات + تثبيت التطبيق.

4 إنشاء بوت تيليجرام وربطه — (اختياري — يمكنك التخطي)

⏭ لا تريد تيليجرام الآن؟ لا مشكلة إطلاقاً. النظام والتطبيق يعملان بالكامل بدونه — تخطَّ هذه الخطوة وانتقل للخطوة 5. الإشعارات ستكون عبر التطبيق نفسه (تفتحه فترى كل جديد)، ويمكنك تفعيل تيليجرام في أي وقت لاحق بالعودة لهذه الخطوة.
💡 بديل خفيف للمتابعة: نزّل تطبيق GitHub الرسمي من متجر التطبيقات وسجّل الدخول — سيصلك إشعار عند كل تشغيل آلي وتتابع حالة المسحات منه مباشرة.

البوت يرسل لك ملخص كل مسح وتنبيهات الصفقات مباشرة على جوالك.

4-1) إنشاء البوت (دقيقتان)

  1. افتح تيليجرام ← ابحث عن @BotFather ← اضغط Start.
  2. أرسل له: /newbot
  3. سيسألك عن اسم البوت — اكتب مثلاً: ماسح بايننس
  4. ثم عن اسم المستخدم (username) — يجب أن ينتهي بكلمة bot مثل: my_sniper_bot
  5. سيرد عليك برسالة فيها التوكن (Token) — يشبه:
    7012345678:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxx
    انسخه واحفظه (لا تشاركه مع أحد).

4-2) معرفة رقم الدردشة (Chat ID)

  1. أرسل للبوت الذي أنشأته أي كلمة (مثل: مرحبا) — هذه خطوة مهمة.
  2. افتح هذا الرابط في المتصفح (استبدل التوكن بالتوكن الخاص بك):
    https://api.telegram.org/botالتوكن-الخاص-بك/getUpdates
  3. ستظهر نصوص كثيرة — ابحث عن جملة تشبه "chat":{"id":5581234567 — الرقم هذا هو Chat ID (قد يكون موجباً أو سالباً). انسخه.

4-3) وضع السريين في GitHub

  1. في المستودع ← Settings ← من القائمة اليسرى: Secrets and variables ← Actions.
  2. اضغط الزر الأخضر New repository secret وأضف سريين:
الاسم (Name)القيمة (Secret)
TELEGRAM_BOT_TOKENالتوكن من BotFather
TELEGRAM_CHAT_IDرقم الدردشة
💡 لا تقلق — «السري» في GitHub يعني القيمة المخفية عن أعين الزوار. مستودعك عام لكن هذه القيم لن يراها أحد.

5 أول تشغيل — شغّل المسح الآن

  1. في المستودع ← تبويب Actions (إذا ظهر لك زر I understand my workflows, go ahead and enable them فاضغطه).
  2. من القائمة اليسرى اختر Binance Futures Scanner (Riyadh Schedule).
  3. اضغط Run workflow ← اترك النوع scan ← اضغط الزر الأخضر Run workflow.
  4. ستظهر دورة صفراء «قيد التنفيذ» ← اضغط عليها وراقب الخطوات (دقيقة إلى 3 دقائق).
  5. عند اكتمالها:
    • 🌐 افتح رابط التقرير (أو التطبيق المثبّت) ← ستراه محدّثاً ببيانات حقيقية.
    • 📱 إن فعّلت تيليجرام لاحقاً ستصلك رسالة ملخص بعد كل مسح تلقائياً.
⚠️ إن كان المسح أحمر (فشل): اضغط على الدورة واقرأ آخر رسالة حمراء — غالباً سببها ملف مرفوع في مكان خاطئ. أعد رفع الملف الناقص وشغّل مرة أخرى. يمكنك أيضاً متابعة حالة كل تشغيل من تطبيق GitHub الرسمي.

6 تثبيت التطبيق على جوالك 📲

التقرير هو التطبيق! بتثبيته يظهر كأيقونة حقيقية على شاشتك الرئيسية يفتحه بنقرة واحدة.

🤖 على أندرويد (متصفح Chrome)

  1. افتح رابط التقرير في Chrome.
  2. سيظهر لك شريط سفلي عائم: 📲 ثبّت التطبيق على جوالك الآن — اضغطه، ثم اضغط Install / تثبيت.
  3. أو يدوياً: اضغط قائمة المتصفح ⋮ ← تثبيت التطبيق (Install app) ← تثبيت.
  4. ستظهر أيقونة التصويب الذهبي 🎯 على شاشتك الرئيسية — اضغطها وستفتح التطبيق في نافذة مستقلة تماماً كأي تطبيق.

🍎 على آيفون (متصفح Safari)

  1. افتح رابط التقرير في Safari (مهم — غير Safari لا يدعم التثبيت).
  2. اضغط زر المشاركة ⬆️ في أسفل الشاشة.
  3. اختر من القائمة: «إضافة إلى الشاشة الرئيسية» (Add to Home Screen).
  4. اضغط «إضافة» في أعلى يمين الشاشة.
  5. ستظهر الأيقونة 🎯 على شاشتك.
✅ بعد التثبيت: التطبيق يعمل بملء الشاشة، ويحتفظ بآخر تقرير حتى بدون إنترنت (يعرض آخر نسخة محفوظة)، وعند توفر إنترنت يتحدث تلقائياً.

⚙️ إعداد الأزرار لتعمل من التطبيق (مرة واحدة فقط)

الأزرار أعلاه تعمل عن طريق إرسال أوامر إلى GitHub — وهذا يحتاج رمز وصول شخصي (PAT) تدخله مرة واحدة:

  1. على المتصفح (أي جهاز) افتح: https://github.com/settings/tokens (وأنت مسجّل الدخول).
  2. اضغط Generate new token ← Generate new token (classic).
  3. في Note اكتب: sniper ← في Expiration اختر No expiration (أو سنة).
  4. ضع علامة ✓ أمام repo (القسم الأول فقط يكفي).
  5. اسحب لأسفل ← Generate token ← انسخ الرمز (يبدأ بـ ghp_) — لا يظهر مرة ثانية.
  6. افتح التقرير ← اضغط ⚙️ إعداد الضغطة الواحدة ← الصق الرمز في الخانة ← اضغط حفظ.
💡 الاسم والإيميل اللذان يظهران في الخانات يملآن تلقائياً — اتركهما كما هما. الرمز يُحفظ داخل متصفحك فقط ولا يظهر لأحد.

يعمل النظام تلقائياً في هذه الأوقات (بتوقيت الرياض) — وهي مضبوطة على أهم فترات السوق (حول إغلاق نيويورك):

كيف أغيّر الجدول؟

في ملف .github/workflows/scanner.yml تجد سطور cron — كل سطر بصيغة دقيقة ساعة * * * بتوقيت UTC (الرياض = UTC + 3 ساعات). مثال: لتضيف مسحاً عند 1:00 ليلاً بتوقيت الرياض (22:00 UTC) أضف سطراً: 0 22 * * *

⚠️ ملاحظة مطمئنة: GitHub أحياناً يؤخر التنفيذ 5–20 دقيقة وقت الازدحام. النظام ذكي ويعرف «الموعد المخطط» فيتعامل مع التأخير دون مشاكل.

🛠 استكشاف الأخطاء الشائعة

❌ لم تصل رسالة تيليجرام بعد التشغيل
  • تأكد أنك أرسلت للبوت كلمة واحدة على الأقل قبل جلب الـChat ID.
  • اسم السر يجب أن يكون بالضبط: TELEGRAM_BOT_TOKEN (حروف كبيرة).
  • أعد نسخ التوكن من BotFather (أمر /token يعطيك توكن جديد).
  • شغّل المسح مرة أخرى من Actions وراقب سجل التنفيذ — سطر Telegram notification sent يعني النجاح.
❌ التقرير لا يفتح أو صفحة 404
  • تأكد أن GitHub Pages مفعّل (Settings ← Pages ← main ← Save).
  • تأكد أن اسم المستخدم والمستودع صحيحان في الرابط.
  • أول مرة قد تنتظر 5 دقائق ثم أعد المحاولة.
❌ زر «ابدأ المسح الآن» لا يعمل
  • هذا الزر يحتاج إعداد ⚙️ (رمز PAT) — راجع قسم «إعداد الضغطة الواحدة».
  • تأكد أن الرابط في الإعداد هو اسمك/sniper (المالك/المستودع).
  • بديل مؤقت: شغّل المسح من تبويب Actions مباشرة.
❌ ظهرت رسالة «الخطوة المطلوبة قديمة» في التقرير

هذه رسالة وقائية تظهر إذا مضت أكثر من ساعة على آخر مسح. شغّل المسح الجديد وستختفي. قد تظهر أيضاً إذا كان الجدول خارج ساعات عمل النظام المتوقعة — طبيعية ولا تدل على عطل.

❌ التطبيق المثبّت يعرض بيانات قديمة

اسحب للأسفل داخل التطبيق للتحديث (أو اضغط ↻ تحديث الصفحة). بدون إنترنت يعرض آخر نسخة محفوظة — وهذا مقصود.

❌ أريد البدء من الصفر وإعادة ضبط كل شيء

اضغط زر 🗑️ ريست: مسح كل الصفقات في أعلى التطبيق ← أكّد. ستمسح كل الصفقات والسجل التراكمي والأرشيف، ويبقى النظام جاهزاً لتسجيل الصفقات الجديدة من المسح القادم.

❓ هل أستطيع تغيير اسم التطبيق على شاشة الجوال؟

نعم — الاسم يظهر من ملف manifest.json (الحقل short_name). عدّله وارفعه مرة أخرى. على الآيفون يمكنك تغيير الاسم عند الإضافة للشاشة الرئيسية.
